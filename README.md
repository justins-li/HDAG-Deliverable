# Meridian Air — Route Network Strategy

HDAG Case Team Analyst deliverable.

> **Recommendation: JFK ⇄ Manchester (MAN).**
> Thomas Cook's September 2019 collapse vacated 47% of a proven, full route. 26,235 Q4
> passengers of demonstrated demand went unserved — at 2018 load factors, **0.83 departures
> per day.** Almost exactly the one rotation Meridian has been funded for.

## Running it

```bash
pip install pandas numpy matplotlib
jupyter notebook HDAG_Case_Team_Deliverable.ipynb   # run all
```

Cell 5 clones the data into `f24-hdag-data/`. The notebook writes the three figures the deck
uses, so run it before re-rendering the deck.

**The notebook is the single entry point.** Its "interactive screen" cell opens the dashboard
in a browser tab *and* embeds it inline, so running the notebook reaches every other artefact.

**The dashboard needs nothing** — no server, no network, no build. Click any row to inspect
that route's carrier mix and Q4 history; the **Definitions** button explains every column.
To open it on its own:

```bash
open dashboard/index.html        # macOS
xdg-open dashboard/index.html    # Linux
```

Re-render the deck to PDF (only if `deck.html` or the figures change):

```bash
python -c "
from playwright.sync_api import sync_playwright; import pathlib
with sync_playwright() as pw:
    b = pw.chromium.launch(); pg = b.new_page()
    pg.goto(pathlib.Path('deck.html').resolve().as_uri()); pg.wait_for_timeout(900)
    pg.pdf(path='Meridian_Air_Route_Recommendation.pdf', width='1280px',
           height='720px', print_background=True, page_ranges='1-5')
    b.close()"
```

## The framing in one table

Opportunity is **demand that already exists, on planes that are already full, on a route
nobody owns** — the Thin Air Index:

| Dial | Question | Measure |
|---|---|---|
| **D** Demand | Is the market real? | Q4 passengers 2015–19 |
| **G** Growth | Is it getting bigger? | vs 2010–14 |
| **S** Strain | Are the planes full? | passengers ÷ departures |
| **R** Room | Can we get in? | 1 − HHI of carrier shares |

## One thing to know before reading any number

The source files are **not full years.** Passenger records run Sep–Dec (1990–2002) then
Aug–Dec; departures Oct–Dec (1990–2010) then Sep–Dec. Every figure here is on a forced
constant **Oct–Dec** window — the only window present in both files in every year — so totals
are Q4 volumes, never annual ones. See `CLAUDE.md` §4.

Data: USDOT T-100 International Report, via
[AnmayG/f24-hdag-data](https://github.com/AnmayG/f24-hdag-data).
